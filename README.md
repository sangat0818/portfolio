# Paban Kumar Adhikari — Portfolio

Personal portfolio site built with Next.js.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Push to GitHub and deploy with [Vercel](https://vercel.com) (or any Next.js host).

Requires Node.js 20+.
